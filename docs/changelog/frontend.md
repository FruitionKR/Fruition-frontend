# 프론트엔드 변경 이력

## 2026-09-22

- Figma 기준 채팅·알림 글꼴과 패딩, 편집기 상하 80px·좌우 40px 여백을 반영했다. 이름의 볼드를 해제하고 채팅 제목 전체 hover를 적용했으며 chat_scroll·chat·empty_chat·send·plus SVG를 용도별 폴더에 정리했다.
- 문서 로딩 안내를 편집기 중앙에 표시한다. 알림 카드의 실제 치수는 브라우저에서 확인했고, Pretendard 폰트와 라이선스를 함께 포함했다.
- 닫힌 이중 달러 수식의 입력·붙여넣기·여러 줄 처리를 보완하고, 빈 수식 생성 즉시 입력창으로 포커스를 이동한다. 슬래시와 선택 툴바의 수식 명령을 통일하고 블록 이동 핸들을 제거했다.
- 같은 원문 블록 집합을 가리키는 채팅 인용 번호를 통합한다. 수식 입력·수정·취소는 실제 브라우저에서 확인했으며 관련 회귀 테스트를 추가했다.
- 문서 업로드·이름 변경 전에 서버 목록을 조회해 동일한 전체 파일명을 차단하고, 실패 시 목록을 갱신한다. 새 노트에는 중복되지 않는 번호를 붙인다. 브라우저 간 동시 요청의 원자적 중복 방지는 서버 제약이 필요하다.
- 그래프 진입 시 원본을 포함한 모든 노드를 표시하고, PDF 변환본이 있으면 Markdown만 표시한다. PDF·폴더 선택과 변환 확인 후 위키 편입을 지원하며 같은 탭의 새로고침 시 대기 작업을 복원한다.
- 검증: 전체 테스트 280개와 프로덕션 빌드(타입·린트 포함) 통과.

## 2026-09-21

- 노트 편집기에 남아 있던 단일 달러 수식 자동 변환을 제거하고, 불러오기·입력·저장 모두 `$$...$$`를 사용하도록 통일했다. 실제 Crepe 인스턴스의 문자 입력, 초기 로드, 수식 저장 후 재파싱, 블록 수식을 확인했으며 전체 테스트 245개와 빌드가 통과했다.
- 금액의 `$`가 수식으로 해석되는 문제를 해결하기 위해 단일 달러 수식 인식을 비활성화했다. 인라인·블록 수식은 `$$...$$`로 작성하며, 기존 `$...$`는 일반 텍스트로 표시된다.
- 검증: 전체 테스트 245개, 프로덕션 빌드(타입·린트 검사 포함), 금액·단일 달러·인라인·블록 수식 렌더링 확인 통과. 로컬 Node.js는 v26.5.0이며 CI는 프로젝트 지정 버전인 24.x를 사용한다.
