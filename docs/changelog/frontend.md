# 프론트엔드 변경 기록

## 2026-10-22

### PostHog 프론트 수집 기반

- 공개 프로젝트 토큰을 런타임에 받아 SDK를 초기화하고, 로그인 식별·로그아웃/세션 만료 초기화·워크스페이스 그룹을 연결했다. 기본값이 false인 `ANALYTICS_ENABLED`와 형식을 검증한 공개 토큰이 모두 있어야 수집하며, 같은 조건으로 CSP 외부 도메인을 허용한다. 개인 키·잘못된 값은 HTML에도 전달하지 않는다.
- 수동 페이지뷰와 인용·편집 검토/거절·되돌리기 미리보기·편입 선택·내보내기 시작·업로드 실패·그래프 보조 이벤트를 추가했다. 질문/작업 요청에는 브라우저 세션 ID를 전달한다.
- 이벤트별 허용 속성만 전송하고 초대/인증 토큰·문서 이름·질문/답변·오류 문자열·SDK 초기 방문 URL을 제거한다. 리플레이와 자동 수집은 비활성화했다. 브라우저 UUID API가 제한돼도 분석 ID 생성이 업로드·내보내기를 막지 않도록 대체 경로를 둔다.
- 적용 계획서의 중복 키, 후속 관찰 마감, 질문 시각 판정과 지표 분모를 보완했다. 서버·AI 이벤트, 운영 토큰 설정과 배포는 미완료다.
- 검증: 전체 테스트 1,541개와 CI 통과. 타입 검사와 프로덕션 빌드 통과, 기존 린트 경고 4건. 동일 빌드의 공개 키·개인 키·수집 중지 설정에서 HTML과 CSP 경계를 확인했다.

### SNB 글꼴과 색상 정렬

- Figma 1540:18070 기준 문서·폴더 이름과 이름 변경 입력을 Pretendard SemiBold(600), body 색상으로 맞췄다. 워크스페이스 이니셜에도 body 색상을 적용했다.
- 검증: Figma 노드 코드·스크린샷 대조, 사이드바 테스트 12개와 프로덕션 빌드 통과.

### 채팅·작업 세션 분리와 문서 안내 위치

- 채팅 질의와 작업 요청을 별도의 서버 대화 세션에 저장하고, 탭마다 마지막 대화 선택과 세션별 입력 초안을 사용자·워크스페이스별로 기억한다. 초안은 브라우저 세션 저장소에 보관한다.
- 비동기 조회·응답·중지와 채팅 내보내기의 대상 세션을 고정해 탭 전환으로 기록이 섞이지 않게 한다. 이전 통합 기록은 보존하고 새 요청은 별도 세션에서 시작한다.
- 작업 대화의 되묻기·답변도 새로고침 뒤 작업 기록으로 복원한다. 대화 준비 실패 알림은 개별 설정으로 제어한다.
- Chrome 탭 제목은 문서·화면 이름 대신 Fruition으로 고정한다. 읽기 전용 안내는 본문 편집기 밖의 문서 제목 위에 표시한다.
- 검증: 테스트 1,529개·프로덕션 빌드 통과. 실제 모델로 질의와 작업을 다른 서버 세션에 저장하고, 초안·작업 이력의 새로고침 복원과 안내 위치를 브라우저에서 확인했다.

### 채팅 목록 로고와 첫 질문 제목 표시

- 현재 대화를 표시하는 흰색 고정 로고를 기존 SVG 모양과 테마 색을 사용하는 마스크로 바꿔 밝은 배경에서도 보이게 한다.
- 로고와 말풍선은 같은 14px 자리로 정렬하고, 제목에만 늘어나는 폭을 적용한다. 새 채팅 버튼의 상하 패딩은 4px로 줄인다.
- AI 제목이 아직 없으면 헤더와 이전 대화 목록에 첫 질문을 최대 30자로 표시한다. 서버의 AI 제목이나 지정한 제목을 우선하며, 표시용 제목을 서버에 저장해 자동 생성을 막지 않는다.
- 제목 조회가 일시적으로 실패해도 정해진 횟수 안에서 다시 확인한다. 이전 대화 제목 보완 조회는 최대 4개로 제한한다.
- 검증: 테스트 1,523개와 프로덕션 빌드 통과. 실제 서버의 신규 대화 AI 제목 생성과 기본 제목의 첫 질문 표시, 라이트·다크 로고 색을 브라우저에서 확인했다.

### 위키 편입 전 최신 문서 저장

- 편집 직후 위키 편입을 누르면 디바운스 대기, 진행 중 저장, 자동 저장을 끈 상태의 최신 본문까지 저장한 뒤 편입한다.
- 저장 실패 또는 저장 중 워크스페이스 변경 시 편입을 중단해 이전 본문으로 처리하지 않도록 한다.
- 검증: 전체 테스트 1,503개와 프로덕션 빌드 통과. 린트 오류 없음, 경고 4건.

### 리뷰 후 저장·편입 보호 보완

- 편입 전 저장이 실패해도 미저장 본문의 이탈 경고와 이동 시 저장을 유지한다. 변경이 없는 문서는 편집 잠금을 잃어도 서버 본문을 편입할 수 있다.
- 문서 이동 뒤 끝난 저장 실패도 다음 저장 성공까지 기억하며, 최신 저장 성공이 앞선 실패 때문에 편입을 막지 않도록 한다. 편집기 생성 전에는 현재 본문 읽기를 건너뛴다.
- 검증: 단독 전체 테스트 1,489개·프로덕션 빌드 통과. 변경 파일 린트 경고·오류 없음. 저장 중 잠금을 잃고 이동하는 경로도 회귀 테스트로 확인했다.

### 알림 종류별 설정과 휴지통 목록

- 모든 알림을 종류별로 제어하고, 전체·그룹 스위치를 껐다 켜도 개별 선택을 유지한다. 기존 알림 설정은 분리된 항목에 이어받는다.
- 그룹 전체 알림 설정을 큰 제목과 같은 줄에 배치하고 맨 위 전체 알림 제목도 같은 크기로 표시한다.
- 휴지통을 설정 본문에서 바로 확인·복구하고, 복구 알림은 설정 화면 우하단에 표시한다.
- 검증: 전체 변경 통합 상태에서 테스트 1,503개와 프로덕션 빌드 통과. 린트 오류 없음, 경고 4건.

### 리뷰 후 알림 전달·피드백 보완

- 브라우저 알림을 별도 전달 방식 그룹으로 분리하고, 즉시 요청 실패와 비동기 작업 실패의 설정을 나눠 기존 실패 피드백을 보존한다.
- 꺼진 작업 알림의 전용 폴링을 멈추고, 다시 켠 시점 이전의 완료를 새 알림으로 보내지 않는다. 설정에서는 위키 작업 제안을 띄우지 않는다.
- 휴지통 복구 성공과 재편입 안내는 카드 설정과 무관하게 본문에도 표시한다.
- 검증: 단독 전체 테스트 1,499개·프로덕션 빌드 통과. 기존 린트 경고 4건 유지.

### 문서 트리와 모델 선택 UI

- 원본 PDF·변환본 배지를 눌러 서로 이동하고, 보기 전용 권한과 긴 문서 이름을 툴팁으로 확인한다. 폴더 추가 버튼과 문서 이름의 겹침을 방지한다.
- 그래프의 위키 편입 선택도 Markdown 전용 트리를 사용하며 수정 없는 최신 문서는 선택에서 제외한다.
- 모델 선택 하위 메뉴 폭과 행 높이를 유지하고 긴 모델 이름은 말줄임·툴팁으로 표시한다.
- 검증: 전체 변경 통합 상태에서 테스트 1,503개와 프로덕션 빌드 통과. 린트 오류 없음, 경고 4건.

### 리뷰 후 트리 드롭·툴팁 보완

- 문서를 드래그하는 동안 변환 배지 링크가 드롭 위치를 가로채지 않도록 해, 문서 행의 묶음 생성 동작을 유지한다.
- 이름 툴팁에는 전체 이름을, 보기 전용 아이콘에만 권한 안내를 표시한다. 클릭 안내는 실제로 이동 가능한 배지 링크에만 붙인다.
- 검증: 단독 전체 테스트 1,482개·프로덕션 빌드 통과. 기존 린트 경고 4건 유지.
